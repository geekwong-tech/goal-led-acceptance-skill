# Fictional example: volunteer handbook

English | [简体中文](example.zh-CN.md)

Goal: a new volunteer can book a first shift without assistance. The draft structure is already approved; the current eligibility rule remains unverified. All links pass automated checks.

An appropriate first response, after inspecting the available draft and decision record:

> We can accept the draft's instructional design today; eligibility accuracy and independent booking success need separate verification. The route is eligibility → choosing a shift → booking → recognizing confirmation. We will start with eligibility.
>
> **Goal and logic:** volunteers must recognize whether they can proceed before choosing a shift.
>
> **Needed answer and basis:** a clear rule, its effective date and an authoritative source. Publication permission is a separate check.
>
> **Actual match:** the draft has an eligibility passage but cites last year's rule. That supports a historical statement, not current eligibility. The current source has not been verified. MACHINE link checks establish reachability only.
>
> **Assessment:** partial for draft design; current factual accuracy is unverified. Keep the passage visibly provisional until the rule owner verifies it. Later, an EXPERIMENT with new volunteers can test whether the instructions enable independent booking.
>
> **Confirm now (HUMAN):** open the eligibility passage. Does it make the decision point understandable enough to accept this draft design, with the current rule explicitly deferred?

Then wait. If the user revises the goal to reducing coordinator workload, revisit the necessary conditions instead of merely continuing the booking checklist. If the user asks to batch the remaining units, do so and identify which judgments remain unconfirmed.

This example is fictional. Its route and wording are illustrations, not mandatory fields for every project.
